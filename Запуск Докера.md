# Запуск Docker

## 1. Системные требования

- Windows 10/11 Pro, Linux или macOS
- 8 GB RAM (рекомендуется 16 GB)
- 20 GB свободного места
- Docker Desktop / Docker Engine + Docker Compose установлены

## 2. Подготовка

```bash
# Скопировать .env и заполнить секреты
cp .env.example .env

# Создать необходимые директории
mkdir -p data/cache data/processed data/result data/history logs
```

## 3. Полный запуск (все сервисы)

```bash
docker compose build
docker compose up -d
```

## 4. Выборочный запуск

```bash
# Без n8n и open-webui
docker compose up -d backend frontend prometheus grafana postgres-exporter node-exporter cadvisor
```

## 5. Проверка

```bash
# Статус контейнеров
docker ps

# Health endpoint
curl http://localhost:8000/health

# Prometheus метрики
curl -s http://localhost:8000/metrics | grep llm
```

## 6. Состав сервисов

| Сервис | Назначение | Порт |
|--------|-----------|------|
| `backend` | FastAPI (основное API) | `:8000` |
| `frontend` | React SPA | `:8080` |
| `competency-postgres` | Основная БД (pgvector) | `:5432` |
| `open-webui` | Веб-чат с LLM (внешняя Ollama: qwen3.6) | `:3000` |
| `n8n` | Автоматизация воркфлоу | `:5678` |
| `n8n-postgres` | БД n8n | — |
| `prometheus` | Сбор метрик (30 дней) | `:9090` |
| `grafana` | Дашборды (admin / 2JQeA2nD7Ndsj1kr) | `:3001` |
| `postgres-exporter` | Метрики PostgreSQL | `:9187` |
| `node-exporter` | Метрики хоста | `:9100` |
| `cadvisor` | Метрики Docker-контейнеров | `:8081` |

## 7. Доступ к сервисам

| Ссылка | Описание |
|--------|----------|
| http://localhost:8080 | Frontend |
| http://localhost:8000/docs | Swagger |
| http://localhost:8000/metrics | Prometheus raw метрики |
| http://localhost:3001 | Grafana (admin / пароль из .env) |
| http://localhost:9090 | Prometheus Web UI |
| http://localhost:5678 | n8n |
| http://localhost:3000 | Open WebUI (чат с Qwen 3.6) |

## 8. Управление

```bash
# Остановить все
docker compose down

# Остановить с удалением томов БД
docker compose down -v

# Перезапустить сервис
docker compose restart backend

# Логи
docker compose logs -f backend

# Пересобрать без кэша
docker compose build --no-cache
```

## 9. Решение проблем

### Open WebUI не видит модель
```bash
docker exec openwebui curl -s http://ollama8.r61.net:11434/api/tags
# Ожидается: {"models":[{"name":"qwen3.6:latest",...}]}
```

### Порт занят
```bash
netstat -ano | findstr :8000
# или на Linux: ss -tlnp | grep 8000
```

### API перезапускается
```bash
docker logs compare-competencies-api --tail=50
```

### cAdvisor не стартует
```bash
docker logs cadvisor --tail=20
# Нужны монтирования /var/lib/docker/ и /sys/
```
