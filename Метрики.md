# Метрики проекта

## 1. LLM (Qwen 3.6)

Используется внешняя Ollama на сервере университета `http://ollama8.r61.net:11434`, модель `qwen3.6:latest` (36B).

| Метрика | Значение | Пояснение |
|---------|----------|-----------|
| **Размер модели** | ~24 GB | Занимает на сервере университета |
| **RAM при инференсе** | зависит от сервера | Внешняя, не расходует ресурсы compareserver |
| **Скорость генерации** | зависит от сервера | Зависит от нагрузки университетского сервера |
| **Длина контекста** | 262144 токенов | Поддерживает vision, completion, tools, thinking |

### Endpoint
```
OLLAMA_URL=http://ollama8.r61.net:11434
OLLAMA_MODEL=qwen3.6:latest
```

### Prometheus-метрики (через backend)

| Метрика | Тип | Labels | Описание |
|---------|-----|--------|----------|
| `llm_requests_total` | Counter | `model`, `status` (ok/error) | Количество LLM-запросов |
| `llm_request_duration_seconds` | Histogram | `model` | Длительность запроса (buckets: 0.1–60s) |

Проверка:
```bash
curl -s http://localhost:8000/metrics | grep llm
```

## 3. Grafana Дашборды

### Server Monitoring (`/d/server-monitoring`)
- CPU Usage, Memory, Disk (gauges)
- CPU Load, CPU/Memory Over Time (timeseries)
- Network Traffic (RX/TX)
- Backend Health, PostgreSQL Connections/Transactions

### Application Monitoring (`/d/app-monitoring`)
- Backend Health, Active DB Connections
- HTTP Requests Rate, Response Time
- PostgreSQL Transactions, Cache Hit Ratio

### LLM & AI Monitoring (`/d/llm-monitoring`)
- LLM Requests Total, Error Rate, Avg/Last Duration
- LLM Request Status Breakdown (pie chart)
- LLM Requests Over Time, Duration Buckets
- Duration Percentiles (P50/P90/P95/P99)
- API Requests to `/api/llm/chat`
- Docker Container CPU/Memory (openwebui, backend, frontend)
- PostgreSQL Cache Hit Ratio

**Доступ:** http://localhost:3001 (admin / 2JQeA2nD7Ndsj1kr)

## 6. cAdvisor (Docker контейнеры)

Доступен через Prometheus job `cadvisor`:

```promql
# CPU контейнера
rate(container_cpu_usage_seconds_total{name=~".*openwebui.*|.*competencies.*"}[5m])

# RAM контейнера
container_memory_usage_bytes{name=~".*openwebui.*|.*competencies.*"}
```

Порт: `:8081`
