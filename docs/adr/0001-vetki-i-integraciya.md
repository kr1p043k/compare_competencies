# ADR 0001: Интеграционная ветка `dev`, `main` не трогают

- Статус: Принято
- Дата: 2026-11-09

## Контекст

Над проектом одновременно работает много сессий (агентов) в общих worktree.
Раньше параллельные правки прямо в `main` и в общих рабочих каталогах
приводили к конфликтам, потерям незакоммиченного кода и нестабильному
состоянию ветки.

## Решение

- Есть интеграционная ветка `dev`. Любая задача делается в отдельной ветке
  от `dev`; готово и зелено (тесты) - merge в `dev`.
- `main` не трогаем: изменения в `main`/прод идут только через владельца.
- Одна рабочая ветка на проект, каждый - в своём worktree; перед правкой файл
  заявляется через координационную шину (`coord.py claim`).
- Перед запуском тестов/серверов проверяем, не идёт ли уже такой процесс.

## Последствия

- Плюс: параллельные сессии не затирают друг друга, состояние `dev` всегда
  проверяемо и зелено.
- Минус: `dev` требует регулярного подтягивания (`origin/dev`) в свою ветку;
  пересечения по файлам решаются через шину.
