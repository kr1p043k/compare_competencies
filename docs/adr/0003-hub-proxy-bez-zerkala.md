# ADR 0003: Хаб ЮФУ - stateless-прокси, без зеркала в БД

- Статус: Принято
- Дата: 2026-11-09

## Контекст

Публикации ЮФУ (hub.sfedu.ru) - большой внешний корпус (133 902 записи).
Варианты: (а) разово выкачать и держать копию в нашей PostgreSQL;
(б) ходить в API хаба на каждый запрос через тонкий прокси.

Корпус чужой, обновляется независимо от нас, а его схема и полнотекстовая
выдача не под нашим контролем. Копия потребовала бы миграций, ретеншена и
регулярной пересинхронизации всего, что расходится с источником.

## Решение

- Хаб - **stateless-прокси**: `src/infrastructure/hub_publications.py` только
  ходит в API хаба (httpx), ничего не пишет в нашу БД. Подтверждено: в модуле
  и роутере нет `INSERT/UPDATE/session/get_pool`.
- Поиск по хабу - серверный скан страниц (ограниченное число), клиент на
  фронте ищет по уже загруженным страницам и честно показывает охват.
- Ответы кэшируются кратко (`Cache-Control`), типы и счётчики - на своё TTL.

## Последствия

- Плюс: нет дублирования чужого корпуса, нет миграций/ретеншена под него;
  всегда актуальные данные источника.
- Минус: зависим от доступности и латентности API хаба; глубокий поиск
  ограничен по объёму (это принято осознанно).
