# Architecture Decision Records (ADR)

Короткие записи о принятых архитектурных решениях: контекст, решение,
последствия. Формат - облегчённый MADR.

## Правила

- Один файл на решение: `NNNN-kratkoe-imya.md` (нумерация по возрастанию).
- Статус: `Принято` / `Устарело` / `Предложено`. Решение не переписывают -
  при изменении заводят новый ADR со ссылкой на предыдущий.
- Пишем по-русски, без длинного тире.
