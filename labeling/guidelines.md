# Разметка релевантности «роль → навык»

## Что делать эксперту

Файл `pairs_excel.csv`: 500 строк — 4 роли × 125 навыков.
Открывается в Excel как есть (UTF-8 с BOM, разделитель «;»).
В колонках `expert1..3` поставьте **свою** оценку (каждый эксперт —
свою колонку, все судят ВСЕ 120 пар — это нужно для согласия).

Шкала (оценивайте для указанной роли, не для себя):

- **2 — ядро**: без этого навыка в роли делать нечего
  (пример: Python для Data Scientist).
- **1 — смежный**: полезен рядом, но не обязателен
  (пример: Docker для Data Scientist).
- **0 — мимо**: к роли не относится
  (пример: 1C для Data Scientist).

Правила:

- Сомневаетесь между 1 и 2 — ставьте 1.
- Незнакомый навык — гуглите 1 минуту, потом ставьте 0.
- Время: ~3–4 часа на все 500 пар. Обязательно разбейте на 3–4 сессии
  (уставший эксперт шумит хуже, чем меньше данных). Между сессиями
  сохраняйте файл.

## Что будет дальше

По трём колонкам считаются: majority-лейбл, согласие экспертов
(Fleiss' kappa) и качество ранжирования системы (NDCG@10) —
скрипт `score.py`. Порог приличия: kappa ≥ 0.4, иначе шкалу
уточняем и переразмечаем спорные пары.
