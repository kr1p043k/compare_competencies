# E2E smoke suite (Playwright)

Минимальный смоук «система живая»: экран логина рендерится, неверные креды
дают ошибку, реальные креды заходят в шелл, бэкенд отвечает на health.
Это НЕ регрессионный набор: быстрые проверки, а не покрытие.

## Как запустить

Тесты сами ничего не поднимают - нужны уже работающие серверы:

```bash
# 1. Backend (порт 8000), из корня проекта
uvicorn src.api_pkg:app --host 0.0.0.0 --port 8000 --reload

# 2. Frontend (порт 3000), отдельный терминал
cd frontend && npm install && npm run dev

# 3. Смоук, из frontend/
npm run test:e2e
```

Браузеры Playwright ставятся один раз:
`npx playwright install chromium`.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `E2E_BASE_URL` | адрес фронтенда (baseURL тестов) | `http://localhost:3000` |
| `API_BASE_URL` | адрес API для health-теста | `http://localhost:8000` |
| `E2E_USER`, `E2E_PASS` | реальные креды для теста валидного входа | нет: тест **пропускается** с явной причиной |
| `E2E_START_WEBSERVER` | `1` = Playwright сам поднимет `npm run dev` (`reuseExistingServer` локально); бэкенд всё равно запускать руками | нет: webServer отключён |

Без бэкенда прогон врёт на каждом шаге: форма входа получает
`Нет связи с сервером` вместо «Неверный логин или пароль», health падает,
а через ~16 секунд App переключается на экран техработ (3 подряд
незаиснивших опроса /api/health, App.tsx:221-242).

## Требования к данным и 2FA

- Тест валидного входа рассчитан на **глобальный рубильник 2FA в OFF**
  (значение по умолчанию): вход по паролю без challenge. С включённым 2FA
  вход админа уйдёт на экран кода, и тест честно упадёт - переведите
  рубильник в OFF перед смоуком.
- Тест неверного входа использует адрес `e2e-smoke@example.com`, которого
  нет в БД: счётчик неудач реальных аккаунтов не трогается. Лимит
  `/api/auth/login` - 10 попыток/мин с одного IP (auth.py:501): не гоняйте
  смоук чаще раза в минуту.

## CI

В CI этот смоук **не запускается**: пайплайнов для e2e пока нет, грины
бэкенда/фронтенда гоняются unit-наборами (pytest/vitest). Запуск - только
локально руками по шагам выше.

## Где что лежит

- `playwright.config.ts` - настройка (chromium-only, baseURL из env,
  trace on-first-retry, webServer только по E2E_START_WEBSERVER);
- `smoke.spec.ts` - сами тесты, селекторы подписаны источниками
  (файл:строка реальной разметки).
